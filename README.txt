外野送球 軌道シミュレーター（試作版）
====================================

使い方
1. index.html をブラウザで開きます。
2. 距離、球速、到達時間、回転数、回転効率、簡易回転方向を入力します。
3. 「軌道を計算」を押します。

iPhoneでの利用
- 手早く試す: index.html をWebサーバー等に置いてSafariで開きます。
- ホーム画面に追加してアプリのように使うには、HTTPSで配信する方法がおすすめです。
- このZIPだけをiPhoneの「ファイル」から開くだけでは、PWAとしてのインストール動作は保証されません。

重要な注意
- 物理係数とマグヌス力モデルは暫定値です。研究用途・選手評価の確定値として使用しないでください。
- 回転軸は簡易選択であり、Rapsodoの3D回転軸データを直接使う実装は未対応です。
- 抗力係数、揚力係数、縫い目効果、風、リリース位置・到達位置の実測補正は未実装です。
- 送球距離・球速・到達時間と物理モデルの整合性を数値探索する初期試作です。
